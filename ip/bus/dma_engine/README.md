# dma_engine

Memory to memory DMA engine. Copies LEN bytes from SRC to DST over one AXI4 master port using burst read and write engines decoupled by a stream FIFO (bursts limited to MAX_BURST beats and never crossing 4 KB). Programmed through the cfg_* / sts_* ports; dma_engine_top.sv is the block with its AXI4-Lite register map (src/include/dma_engine_regs.sv: ID "DMAE" / VERSION / DATE at 0x00-0x08) - 0x10 CTRL [0]start (pulse) [1]irq_en, 0x14 SRC, 0x18 DST, 0x1C LEN (bytes, multiple of 4), 0x20 STATUS [0]busy [8]done (W1C) [9]error (W1C). irq_o follows done when enabled. Addresses must be 4 byte aligned. Clock - single clock aclk, every input is synchronous to it unless a two-flop synchronizer is mentioned. Reset - synchronous active low aresetn, registers take the documented reset values. Latency - AXI-Lite write response and read data follow the request by about 2 to 3 clocks (ip_axil_regs, registered read path). Timing - registered outputs, no combinational path from the bus to the pins. Errors - out of range AXI-Lite accesses return SLVERR; illegal parameter values stop elaboration with an $error. The AXI4 master follows the AXI4 rules of 4 KB burst boundaries; a bus error response stops the transfer and is reported in STATUS.

dma_engine is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `dma_engine_tb` | `test_id_block` | ID "DMAE", VERSION ("d.dd"), DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only (SLVERR); 0x0C reads 0 (register offsets from bfm.base = 0x10, the map after the ID block) |
| `dma_engine_tb` | `test_small` | Small aligned copy (one burst) |
| `dma_engine_tb` | `test_cross_4k` | Source and destination cross 4 KB, length not a burst multiple |
| `dma_engine_tb` | `test_17_words` | 17-word copy |
| `dma_engine_tb` | `test_bus_error` | Destination beyond the memory: SLVERR sets ERROR |
| `dma_engine_tb` | `test_bad_len` | An invalid length is rejected |
