# ddr_ctrl

ddr_ctrl with its AXI4-Lite register interface, the block designs and testbenches instantiate: the register map ddr_ctrl_regs (u_regs, src/include/ddr_ctrl_regs.sv, ID "DDRC", VERSION and DATE at 0x00-0x08, the registers from 0x10) and the logic ddr_ctrl (u_core, src/ddr_ctrl.sv), joined by the register interface ddr_ctrl_regs_if (u_regs_if). Generated by ip/scripts/regmap_gen.py from ddr_ctrl_regs.json and the ports of ddr_ctrl: regenerate after changing either. Clock - clk. Reset - synchronous active low rst_n.

ddr_ctrl is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `ddr_ctrl_tb` | `test_register_map` | ID, VERSION, idle STATUS, SLVERR on a write to a read-only register |
| `ddr_ctrl_tb` | `test_write_read` | Bursts of 1 .. 16 beats on each port, across columns, banks and rows, read back |
| `ddr_ctrl_tb` | `test_both_ports` | Both ports write and read their own data at once (same bank, other rows: PRE / ACT between the bursts) |
| `ddr_ctrl_tb` | `test_strobes` | Partial WSTRB writes keep the other bytes |
| `ddr_ctrl_tb` | `test_errors` | SLVERR (size, FIXED burst) and DECERR (beyond the memory): read data 0, memory untouched |
| `ddr_ctrl_tb` | `test_refresh` | About one REF per T_REFI while idle |
| `ddr_ctrl_tb` | `test_statistics` | RD / WR beats, ACTs, HITS, REFS, ERRS against the DFI commands; CTRL[0] clears them |
| `ddr_ctrl_tb` | `test_timing_kept` | ddr_mem reported no timing violation |
