# ddr_mem

Generic DDR memory for simulation: a behavioural model of an external SDRAM behind a DFI-style command
interface (one command per clock), with the timing checks of a JEDEC SDRAM. It answers the generic build of
`ddr_ctrl` in simulation; a vendor build replaces controller and PHY. See the header of `src/ddr_mem.sv`
for the full specification.

ddr_mem is an IP of the FPGA Cores 4 U digital IP library.

## Directory structure

| Path | Contents |
|------|----------|
| `src/` | RTL (simulation model) |
| `model/` | `ddr_mem_model.py`: the clock-exact Python model |
| `tb/` | self-checking directed testbench, tests in `tb/tests/` |
| `tb/python/` | cocotb test of the RTL against the model (`python3 tb/python/run_python.py`, run by `make test`) |
| `scripts/` | file lists (`build.f`) and flow scripts |
| `docs/` | prompt, industry reference check |

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `ddr_mem_tb` | `test_write_read` | Writes and reads back over two banks and rows, partial strobes, unwritten words read 0 |
| `ddr_mem_tb` | `test_timing_checks` | Each of tRCD, tRP, tRAS, tWR, tRFC and a closed bank sets err_o with its code |
| `ddr_mem_tb` | `test_refresh_deadline` | No REF for REF_MAX clocks sets code 11 |
