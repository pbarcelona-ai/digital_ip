# reset_ctrl

Reset synchronizer logic. Synchronizes an asynchronous external reset for the AXI-Lite bus (bus_rst_n_o, never affected by the soft reset, so the registers survive it) and for NUM_OUT replicated user resets (fan-out control), with a software reset, a hold time, a reset event counter and status on the cfg_* / sts_* ports. ip_reset_sync_top.sv is the block with its AXI4-Lite register map (src/include/ reset_ctrl_regs.sv: ID "RSTC" / VERSION / DATE at 0x00-0x08, 0x10 CTRL [0]=soft reset (self clearing), 0x14 HOLD cycles, 0x18 STATUS[0]=active [1]=event seen (W1C), 0x1C event count). Clock - aclk, the external reset arst_i is asynchronous and is synchronized with STAGES flops. Reset - the reset asserts asynchronously and releases synchronously; outputs are held for the programmed hold (HOLD_DEFAULT at reset). Latency - release is STAGES+1 clocks after arst_i deasserts plus the hold. Errors - illegal parameters stop elaboration.

reset_ctrl is an IP of the FPGA Cores 4 U digital IP library.
