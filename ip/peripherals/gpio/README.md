# gpio

General purpose I/O logic with WIDTH pins: per-pin direction, output register with atomic SET / CLEAR / TOGGLE, two-flop input synchronizers, per-pin rising / falling edge detection into the write-1-to-clear INT_STATUS, and a registered interrupt output irq_o = |(INT_STATUS & INT_EN). Tri-state style pins (gpio_t = 1 means input). Its registers come and go on the cfg_* / sts_* ports; gpio_top.sv is the block with its AXI4-Lite register map (src/include/gpio_regs.sv: ID "GPIO" / VERSION / DATE at 0x00-0x08, OUT 0x10, DIR 0x14, IN 0x18, SET 0x1C, CLEAR 0x20, TOGGLE 0x24, INT_EN 0x28, RISE_EN 0x2C, FALL_EN 0x30, INT_STATUS 0x34). Clock - single clock aclk; gpio_i is synchronised by two flops. Reset - synchronous active low aresetn. Timing - registered outputs, no combinational path from the bus to the pins.

gpio is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `gpio_tb` | `test_id_block` | ID "GPIO", VERSION ("d.dd") and DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only; 0x0C reads 0 |
| `gpio_tb` | `test_reset` | Pins reset to inputs, OUT / INT_STATUS read 0 |
| `gpio_tb` | `test_output` | DIR and OUT drive the pins; atomic SET / CLEAR / TOGGLE; SET / CLEAR / TOGGLE read 0 (write only) |
| `gpio_tb` | `test_input` | IN reads the two-flop synchronised pin levels |
| `gpio_tb` | `test_edge_irq` | Rising / falling edge enables, INT_STATUS write 1 to clear, INT_EN masking of irq_o |
| `gpio_tb` | `test_ro_write` | A write to IN (read only) answers SLVERR |
