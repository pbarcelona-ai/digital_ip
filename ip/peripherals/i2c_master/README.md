# i2c_master

I2C master logic. The registers (cfg_* / sts_* ports) start and describe a transaction; write data is taken from an AXI-Stream slave port and read data is returned on an AXI-Stream master port (tlast marks the last byte). Open-drain pins use i/o/t style signals. i2c_top.sv is the block with its AXI4-Lite register map (src/include/i2c_master_regs.sv: ID "I2CM" / VERSION / DATE at 0x00-0x08, CTRL 0x10 [0] en [1] start (pulse) [2] read [3] no_stop; ADDR 0x14 [6:0]; LEN 0x18; DIV 0x1C (phase clocks - 1, f_scl = f_clk / (4 * (DIV + 1))); STATUS 0x20 [0] busy [1] done [2] nack [3] arb_lost, [3:1] write 1 to clear, [31:16] receive FIFO level). Clock - single clock aclk. Reset - synchronous active low aresetn. Timing - registered outputs, no combinational path from the bus to the pins. Errors - illegal parameter values stop elaboration with an $error.

i2c_master is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `i2c_master_tb` | `test_id_block` | ID "I2CM", VERSION ("d.dd"), DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only (SLVERR); 0x0C reads 0 |
| `i2c_master_tb` | `test_default_div` | DIV resets to CLK_HZ / (4 * SCL_HZ) - 1 (249: 100 kHz at 100 MHz), then 12 for a fast simulated bus |
| `i2c_master_tb` | `test_write` | Pointer 0x10 and two data bytes written to the EEPROM model, STOP leaves the bus idle |
| `i2c_master_tb` | `test_repeated_start_read` | Pointer write without STOP, repeated START read of 2 bytes, tlast on the last byte only |
| `i2c_master_tb` | `test_nack` | An absent target NACKs the address; STATUS W1C clears the flags |
| `i2c_master_tb` | `test_probe` | Address-only probe (LEN 0) of a present target |
| `i2c_master_tb` | `test_stretch` | Read with clock stretching by the target |
