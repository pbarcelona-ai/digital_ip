# intc

Interrupt controller logic with NUM_IRQ sources. Each source has enable, edge or level type, polarity, and software set. Edge sources latch into a pending register cleared by write-1-to-clear, level sources follow the input. A lowest-index-wins priority encoder reports the active vector (pipelined) and the irq output. Its registers come and go on the cfg_* / sts_* ports; intc_top.sv is the block with its AXI4-Lite register map (src/include/intc_regs.sv: ID "INTC" / VERSION / DATE at 0x00-0x08, ENABLE 0x10, EDGE_TYPE 0x14, ACTIVE_LOW 0x18, PENDING 0x1C (W1C for edge bits), SOFT_SET 0x20 (write), VECTOR 0x24 [4:0] id [31] valid, MASKED 0x28). Clock - single clock aclk; irq_i is synchronised by two flops. Reset - synchronous active low aresetn. Errors - illegal parameter values stop elaboration with an $error.

intc is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `intc_tb` | `test_id_block` | ID "INTC", VERSION ("d.dd"), DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only (SLVERR); 0x0C reads 0 (register offsets from bfm.base = 0x10, the map after the ID block) |
| `intc_tb` | `test_level` | Enabled level source 5 raises irq_o and VECTOR, drops with the source |
| `intc_tb` | `test_priority` | Sources 9 and 3: the lowest index wins |
| `intc_tb` | `test_edge` | Edge source 7 latches in PENDING until written with 1 |
| `intc_tb` | `test_active_low` | ACTIVE_LOW: a low input is asserted |
| `intc_tb` | `test_mask` | A source not enabled does not interrupt |
| `intc_tb` | `test_soft_set` | SOFT_SET sets a source pending, PENDING W1C clears it |
