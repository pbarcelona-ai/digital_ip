# spi_master

SPI master logic. AXI-Stream slave carries words to transmit (tlast ends a chip select burst), AXI-Stream master returns the words captured from MISO; the registers come and go on the cfg_* / sts_* ports. spi_top.sv is the block with its AXI4-Lite register map (src/include/spi_master_regs.sv: ID "SPIM" / VERSION / DATE at 0x00-0x08, CTRL 0x10 [0] en [1] cpol [2] cpha [3] lsb_first [15:8] cs_select; DIV 0x14 (SCLK half period = DIV + 1 clocks); WORD_LEN 0x18 bits per word (1..DATA_W); STATUS 0x1C [0] busy [1] rx_overrun (W1C) [31:16] rx fifo level). Any clock frequency, default 1 MHz SCLK at 100 MHz. Clock - single clock aclk. Reset - synchronous active low aresetn. Timing - registered outputs, no combinational path from the bus to the pins. Errors - illegal parameter values stop elaboration with an $error.

spi_master is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `spi_master_tb` | `test_id_block` | ID "SPIM", VERSION ("d.dd"), DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only (SLVERR); 0x0C reads 0 |
| `spi_master_tb` | `test_default_div` | DIV resets to CLK_HZ / (2 * SCLK_HZ) - 1, then 4 (fast SCLK for the simulation) |

| `spi_master_tb` | `test_burst` | Burst of 3 words, CS held low until tlast |
