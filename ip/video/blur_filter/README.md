# blur_filter

Blurring filter for AXI4-Stream video. Version: the VERSION register. conv2d_filter whose reset kernel is a binomial (Gaussian) blur, [1 4 6 4 1] x [1 4 6 4 1] / 256 for N = 5 ([1 2 1] x [1 2 1] / 16 for N = 3). The kernel and SHIFT stay programmable over AXI4-Lite (same register map as conv2d_filter, ID "BLRF", blur_filter_regs.sv): e.g. a 3 x 3 kernel inside the 5 x 5 for a lighter blur, or another strength. FRAME_SIZE must match the video. Clock - clk. Reset - synchronous rst_n (active low).

blur_filter is an IP of the FPGA Cores 4 U digital IP library.
