# object_tracker

Object search / measurement for target tracking. Watches an AXI4-Stream video (24-bit pixels, tuser = start of frame, tlast = end of line) without touching it: a passive tap on the accepted beats (tvalid & tready). Per frame it finds the pixels of its object class inside a search window, reports their bounding box and groups them into up to 8 separate objects (blobs), so the CPU can track several targets of the class and draw them with symbol_overlay. - Object pixel: luma Y = (R + 2 G + B) / 4 below / above THRESH (CTRL.POL), or in colour mode (CTRL.MODE) Y, Cb, Cr inside Y_RANGE / CB_RANGE / CR_RANGE with saturation at least SAT_MIN (skin tone, car paint). - Features: `feat_i` carries feature_detect's edge and motion bits of the beat. The object pixel test has two terms: term A is the luma / colour test combined with the motion bit (CTRL.FEAT_A: the test, OR, AND, motion only), term B (CTRL.TERM_B) the edge bit with its own run band RUN_B; each term has its own run filter and, with TERM_B, its own half of the blob slots. - Run filter: a horizontal run of object pixels counts when its whole length is MIN_W .. MAX_W (RUN, or CTRL.MIN_RUN), also where it crosses the window edge (a bus reaching into a car's window stays a bus-length run); its pixels inside the window are measured. - Blobs: the counted runs are grouped in one pass (no frame store): a run joins the blob it touches (within BLOB_CFG.GAP columns, GAP_Y + 1 lines), runs touching several blobs join them; a closed blob smaller than BLOB_CFG.KEEP is dropped and its slot reused. BLOB_X / BLOB_Y / BLOB_N[0..7] hold the blobs of the last frame, STATUS.BLOB_LOST the runs that found no slot. - At the end of the frame (the tlast of line FRAME_SIZE height - 1) COUNT, BOX_X, BOX_Y, the sums and the blobs are latched, FRAMES increments and done_o pulses for one clock. COUNT = 0: nothing found (the box then reads x0 > x1). - SCRATCH[0..27]: CPU words for the tracking state of the class's targets. Registers on the cfg_* / sts_* ports; object_tracker_top.sv is the block with its AXI4-Lite register map (src/include/object_tracker_regs.sv, ADDR_W = 8): ID "OTRK" / VERSION / DATE at 0x00-0x08, CTRL 0x18, FRAME_SIZE 0x1C, THRESH 0x20, WIN_X 0x24, WIN_Y 0x28, FRAMES 0x2C, COUNT 0x30, BOX_X 0x34, BOX_Y 0x38, SUM_X 0x3C, SUM_Y 0x40, STATUS 0x44, RUN 0x48, Y_RANGE 0x4C, CB_RANGE 0x50, CR_RANGE 0x54, SAT_MIN 0x58, BLOB_CFG 0x5C, SCRATCH 0x60, RUN_B 0xD0, BLOB_X 0x100, BLOB_Y 0x120, BLOB_N 0x140 (8 blobs; ADDR_W = 9). Clock - clk (pixel clock). Reset - synchronous active low rst_n. Latency - results one clock after the last pixel of the frame.

object_tracker is an IP of the FPGA Cores 4 U digital IP library.
