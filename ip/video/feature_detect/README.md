# feature_detect

Edge and motion features of an AXI4-Stream video (24-bit pixels, tuser = start of frame, tlast = end of line) for object detectors. A passive tap on the accepted beats: for every beat it gives two feature bits of that pixel (`feat_o`, the same clock), which `object_tracker` detectors watching the same stream combine with their luma / colour tests. - **Edge** (`feat_o[0]`): the 3 x 3 Sobel magnitude |Gx| + |Gy| of luma Y = (R + 2G + B) / 4, window centred one line and one pixel behind the beat (two line buffers), above EDGE.THRESH, then filled along the line over EDGE.SPAN pixels so textured objects give solid runs. - **Motion** (`feat_o[1]`): a background of 2^CELL_LOG2-pixel square cells holding each cell's lowest and highest luma (4 fraction bits, two banks swapped per frame); a pixel outside [lo - MOTION.THRESH, hi + MOTION.THRESH] of the cell it came from moves (filled over MOTION.SPAN); the background learns 1 / 2^MOTION.RATE of each frame. The first frame after CTRL.RESTART only fills it. - **Camera shift**: column and row luma profiles per cell, compared with the previous frame's by a sum of absolute differences over +-SHIFT_MAX cells (one term per clock after the frame), so a panning camera does not make the whole scene move (CTRL.AUTO_SHIFT, or SHIFT from the CPU). - Per frame EDGE_COUNT, MOTION_COUNT, FRAMES; done_o after the counts and the shift search. Parameters MAXW / MAXH (line buffers, cells), CELL_LOG2, SHIFT_MAX. The design and its parameters were chosen with the Python prototype `image_processing/video_processor/python-prototype/detect_proto.py`; `ip/video/video_tb_lib/feature_ref.sv` is the testbench model. Registers: ID "FEAT" / VERSION / DATE at 0x00-0x08, CTRL 0x18, FRAME_SIZE 0x1C, EDGE 0x20, MOTION 0x24, SHIFT 0x28, SHIFT_EST 0x2C, STATUS 0x30, FRAMES 0x34, EDGE_COUNT 0x38, MOTION_COUNT 0x3C, SHIFT_USED 0x40. Clock - clk (pixel clock). Reset - synchronous active low rst_n.

feature_detect is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `feature_detect_tb` | `test_id_block` | ID "FEAT", VERSION ("d.dd") and DATE (BCD mm/dd/yyyy) at the base address, read only (SLVERR); the rest of the map from 0x10 |
| `feature_detect_tb` | `test_registers` | reset values (EDGE 0x00080080, MOTION 0x00002214, no frame, background not valid) and read back |
| `feature_detect_tb` | `test_edges` | A bright square and a vertical and a horizontal line on a flat scene: edges only around them, at thresholds 64, 200 and 2040 (none) |
| `feature_detect_tb` | `test_edge_span` | The same scene with EDGE.SPAN 0, 1, 3 and 15 |
| `feature_detect_tb` | `test_motion` | A square moving over a still texture: no motion on the first frame (background filling), then motion where the square is and was |
| `feature_detect_tb` | `test_restart` | CTRL.RESTART: the next frame fills the background again (no motion), the frame after it detects |
| `feature_detect_tb` | `test_rate` | A square that stops: its motion fades as the background learns it, faster at RATE 1 than RATE 3 |
| `feature_detect_tb` | `test_pan_auto` | A texture panning 1 cell right and 1 down per frame with CTRL.AUTO_SHIFT: SHIFT_EST finds it, the next frames use it, and only the moving square moves |
| `feature_detect_tb` | `test_manual_shift` | The pan with SHIFT written by the CPU (AUTO off) |
| `feature_detect_tb` | `test_disable` | CTRL.EN = 0: no frame counted, no done_o |
| `feature_detect_tb` | `test_random` | Random scenes, thresholds, spans, rates and shifts with stalls |
