# feature_detect

Edge, motion and sky features of an AXI4-Stream video (24-bit pixels {B, G, R}, tuser = start of frame, tlast = end of line) for object detectors. Version 2.0.0. A tap on the accepted beats of s_axis (tvalid & tready; it never stalls the stream): every beat is forwarded on m_axis two clocks later (tvalid one clock per beat; m_axis.tready is not used) with feat_o, the feature bits of that pixel ([0] edge, [1] motion; 0 while the frame is not processed), so object_tracker detectors watching m_axis get the bits with their beat. Golden model: ip/video/feature_detect/model/feature_detect_model.py (its header defines every bit and register; tb/python compares them). - A frame is processed when CTRL.EN is set at its start; CTRL, EDGE, MOTION, SHIFT and SKY_CFG are taken at the frame start. FRAME_SIZE must be the frame's size (the frame end and the cells come from it). - Luma Y = (R + 2 G + B) / 4: a shift-add approximation of BT.601 luma (ITU-R BT.601-7: 0.299 R + 0.587 G + 0.114 B); blue weighs 0.25 instead of 0.114, so blue objects look brighter to the tests. - Edge (feat_o[0]): the Sobel |Gx| + |Gy| of the 3 x 3 window ending at the pixel (rows y - 2 .. y, columns x - 2 .. x; x, y >= 2) above EDGE.THRESH, filled along the line over EDGE.SPAN pixels. - Motion (feat_o[1]): cells of 2^CELL_LOG2 pixels square (cw = width >> CELL_LOG2 by ch = height >> CELL_LOG2); per cell the lowest / highest luma x 16 in two background banks (one read during a frame, the other written; they swap at the frame end); a pixel moves when the background is valid, its source cell (cx - sx, cy - sy) is in the frame and its luma is below lo / 16 - MOTION.THRESH or above hi / 16 + MOTION.THRESH; filled over MOTION.SPAN. At its last pixel each cell is written: old + (new - old) >>> MOTION.RATE of its source, or the new values without a valid source. The first frame after a restart only fills the background. - Camera shift: column / row luma profiles per cell column / cell row in three rotating banks; after a frame with a previous one a search (per axis the shift -SHIFT_MAX .. SHIFT_MAX with the lowest sum of |cur[i] - prev[i - s]| over i = SHIFT_MAX .. n - 1 - SHIFT_MAX; 0 first, a later shift only when strictly lower; one term per clock, STATUS.BUSY) runs during the next frame -> SHIFT_EST; with CTRL.AUTO_SHIFT a frame uses the estimate of the search that ended two frames before it (the search after frame N, frame N + 2), else SHIFT. - Sky: per column group of 2^SKY_CFG.SHIFT pixels (32 groups) the lines from the top to its first pixel with the edge bit or a luma below SKY_CFG.Y_MIN (the frame height when none) -> SKY[0..31]. - Restart (a CTRL write with RESTART, or a FRAME_SIZE write): at the next frame start the background, profiles and shift start again. - Per frame EDGE_COUNT, MOTION_COUNT, FRAMES; done_o pulses once a frame's results and its shift search are complete. Memories: the luma line buffer, the background banks and the column profiles are read with a registered read (block RAM); cell addresses are counted, not multiplied. Limits: frames of at least SHIFT_MAX + 2 cells each way and more beats than the search's clocks (about (2 SHIFT_MAX + 1) (cw + ch)); CELL_LOG2 >= 1. Registers on the cfg_* / sts_* ports; feature_detect_top.sv is the block with its AXI4-Lite register map (src/include/feature_detect_regs.sv, ADDR_W = 8): ID "FEAT" / VERSION / DATE at 0x00-0x08, CTRL 0x18, FRAME_SIZE 0x1C, EDGE 0x20, MOTION 0x24, SHIFT 0x28, SHIFT_EST 0x2C, STATUS 0x30, FRAMES 0x34, EDGE_COUNT 0x38, MOTION_COUNT 0x3C, SHIFT_USED 0x40, SKY_CFG 0x44, SKY 0x80 + 4 i. Clock - clk (pixel clock). Reset - synchronous active low rst_n.

feature_detect is an IP of the FPGA Cores 4 U digital IP library.
