# frame_counter

Frame counters with an event log for a video pipeline. Version: VERSION register (frame_counter_regs.sv). NCH 32-bit counters, each advanced by a frame marker pulse (eof_i[i], one clock; an end or a start of frame at some point of the pipeline): in video_processor channel 0 counts the frames leaving the first pipeline stage (csi2_raw_unpack) and channel 1 the frames reaching the last stream stage (into axis_to_video). Every marker also sets STATUS[i]; irq_o[i] = STATUS[i] & IRQ_EN[i] (level, until the CPU writes 1 to STATUS[i]), so the CPU can read COUNT[i] at each end of frame. A marker in the same clock as a CLEAR still counts (the counter becomes 1). Event log: every marker of a channel enabled in EV_EN is queued, in the order the markers happened, in an EVQ-entry FIFO with its channel, the channel's count after the marker and a timestamp (TIME, a free-running counter advanced every TS_DIV clocks: TS_DIV = clock MHz gives microseconds). Markers of several channels in one clock are queued lowest channel first (same timestamp). The CPU reads the oldest entry (EVENT, EVENT_TIME) and removes it by writing EVENT_POP; reading has no side effect. A marker that finds the log full is lost and sets EVENT[30] (overflow) until EVENT_POP[1] clears it. Registers: frame_counter_regs.sv holds the register map (AXI4-Lite slave, ADDR_W = 8): ID "FCNT" / VERSION / DATE at 0x00-0x08, IRQ_EN 0x18, STATUS 0x1C, CLEAR 0x20, EVENT 0x24, EVENT_TIME 0x28, EVENT_POP 0x2C, COUNT[i] 0x30 + 4 i, TIME 0x50, EV_EN 0x54; this module instantiates it (u_regs) and connects its register ports. Clock - clk (the pipeline pixel clock). Reset - synchronous active low rst_n.

frame_counter is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `frame_counter_tb` | `test_registers` | reset values of IRQ_EN, STATUS, EVENT, EV_EN and every COUNT |
| `frame_counter_tb` | `test_count` | Pulses on single channels and on several at once are counted per channel |
| `frame_counter_tb` | `test_irq` | irq_o = STATUS & IRQ_EN per channel; STATUS stays set until written with 1 (write 0 keeps it) |
| `frame_counter_tb` | `test_clear` | CLEAR zeroes only the channels written with 1 |
| `frame_counter_tb` | `test_clear_collision` | An end of frame in the clock of a CLEAR counts (the count becomes 1) and one in the clock of a STATUS clear keeps STATUS set |
| `frame_counter_tb` | `test_random` | 2000 clocks of random pulses with random CLEAR, STATUS and IRQ_EN writes, checked against the model after every register access |
| `frame_counter_tb` | `test_time` | TIME advances by one every TS_DIV clocks |
| `frame_counter_tb` | `test_event_order` | Markers on every channel, apart and interleaved: logged in marker order with the channel's count and the timestamp of the marker; reading EVENT does not remove it, EVENT_POP does |
| `frame_counter_tb` | `test_event_same_clock` | Markers of several channels in one clock and a lower channel in the next clock: one timestamp, lowest channel first, the later marker after them |
| `frame_counter_tb` | `test_event_overflow` | More markers than the log holds: the first EVQ kept in order, EVENT[30] set until EVENT_POP[1] |
| `frame_counter_tb` | `test_event_disabled` | A channel not enabled in EV_EN is counted but not logged |
| `frame_counter_tb` | `test_id_block` | ID, VERSION ("d.dd") and DATE (BCD mm/dd/yyyy) at the base address, read only; the map after them at 0x10 |
