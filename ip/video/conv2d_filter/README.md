# conv2d_filter

Programmable N x N convolution filter: conv2d_core with an AXI4-Lite register map. Version: the VERSION register. The kernel defines the filter (blur, sharpen, edge detect, emboss, identity ...); blur_filter and sharpen_filter are this module with other reset kernels. Registers: conv2d_filter_regs.sv holds the register map (AXI4-Lite slave, ADDR_W = 8): ID "C2DF" / VERSION / DATE at 0x00-0x08, FRAME_SIZE 0x14, SHIFT 0x18, STATUS 0x1C ([15:0] frames filtered), INFO 0x20, K[i] 0x50 + 4 i (signed, i = r*N + c); the settings apply from the next frame start. Datapath: conv2d_filter_core. New FRAME_SIZE / SHIFT / K values are taken at the next frame start (they are copied when a start-of-frame pixel enters, so a frame always uses one complete kernel). out = clamp((sum(K*p) + round) >>> SHIFT). Data - AXI4-Stream video, C components of CW bits, tuser = SOF, tlast = EOL. Clock - clk (stream and registers). Reset - synchronous rst_n (active low). Latency - see conv2d_core.

conv2d_filter is an IP of the FPGA Cores 4 U digital IP library.
