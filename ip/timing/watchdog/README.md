# watchdog

Watchdog timer logic: a prescaler (PRESCALE + 1 clocks per tick), a tick counter restarted by a keyed kick (0x5AFEC0DE), a pre-timeout interrupt, an optional window (kicks before WINDOW_OPEN are early and reset), a lock bit that prevents disabling, and a stretched system reset output (RESET_CYCLES clocks). Its registers come and go on the cfg_* / sts_* ports; watchdog_top.sv is the block with its AXI4-Lite register map (src/include/watchdog_regs.sv: ID "WDOG" / VERSION / DATE at 0x00-0x08, CTRL 0x10 [0] en [1] window_en [2] lock, TIMEOUT 0x14 ticks, PRESCALE 0x18, PRETIMEOUT 0x1C ticks, WINDOW_OPEN 0x20 ticks, KICK 0x24, STATUS 0x28 [0] pretimeout [1] expired [2] early kick [3] bad key (W1C), COUNT 0x2C). Clock - single clock aclk. Reset - synchronous active low aresetn. Errors - illegal parameter values stop elaboration with an $error.

watchdog is an IP of the FPGA Cores 4 U digital IP library.

## Tests

| Testbench | Test | Description |
|-----------|------|-------------|
| `watchdog_tb` | `test_id_block` | ID "WDOG", VERSION ("d.dd"), DATE (BCD mm/dd/yyyy) at 0x00-0x08, read only (SLVERR); 0x0C reads 0 (register offsets from bfm.base = 0x10, the map after the ID block) |
| `watchdog_tb` | `test_setup` | TIMEOUT 100 ticks of 4 clocks, pre-timeout at 60, enabled |
| `watchdog_tb` | `test_kicks` | Regular kicks keep it alive |
| `watchdog_tb` | `test_timeout` | Pre-timeout interrupt, then the timeout reset (stretched pulse); STATUS write 1 to clear |
| `watchdog_tb` | `test_bad_key` | A kick with a wrong key is ignored and flagged |
| `watchdog_tb` | `test_window` | Window mode: a kick before WINDOW_OPEN resets, one after it is accepted |
| `watchdog_tb` | `test_lock` | LOCK keeps the watchdog enabled |
