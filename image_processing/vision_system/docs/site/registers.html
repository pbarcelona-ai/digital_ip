All addresses are byte offsets. Coefficients and coordinates use signed Q16.16 unless noted. Geometry writes trigger reciprocal recalculation; wait for STATUS.recip_busy to clear before capturing a frame.

Programming notes

02 / OPERATION

Geometry updates

Writes to image size, calibration mode, center/scale, or intrinsics retrigger reciprocal calculation. Gate frame capture on recip_busy=0.

Frame stability

Set interpolation and distortion mode before a frame begins. These controls are not intended to change mid-frame.

Model availability

Radial, fisheye, panoramic, and perspective are implemented. Affine and scaling currently select an identity fallback.
