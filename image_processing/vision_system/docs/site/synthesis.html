How to read this

01 / LIMITATIONS

Timing is an estimate, not static timing analysis. est_timing.py applies an explicit per-cell delay model to a flattened Yosys netlist. It does not include actual placement and routing, so the result is a proxy for comparing RTL paths, not a timing-closure guarantee.

Utilization comes from the hierarchical stat report after synth_xilinx -family xc7. The integrated src row represents the top-level design; standalone ip/ rows characterize reusable blocks in isolation.

Detailed scripts: summarize.py · est_timing.py · yosys_common.ys
