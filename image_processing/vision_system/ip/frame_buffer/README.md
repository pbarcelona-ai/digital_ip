# frame_buffer

Reusable IP. Full-frame pixel store, four-way replicated so all four bilinear corner samples (or, in bicubic/slow-path modes, one row of four taps at a time) can be read in a single cycle. Sized to MAX_W*MAX_H; real geometry is runtime-programmable.

frame_buffer is design-local IP of [`vision_system`](../../README.md).
