# ddr_frame_store

vision_system's frame store in DDR (USE_DDR_FB), an AXI4 master of the shared DDR controller (ip/memory/ddr_ctrl). Version 1.0.0. Golden model: model/ddr_frame_store_model.py (clock exact; tb/python, with ddr_ctrl and ddr_mem). - Two frame buffers in DDR at byte addresses BASE0 / BASE1 (wr_buf / rd_buf choose one per access); pixel a of buffer b is the 32-bit slot at BASE<b> + 4 a, the pixel in its low PIX_W bits (the rest 0). Every slot must lie in the memory behind the controller: BRESP / RRESP are not checked, read data is used as returned. - Writes (wr_en with wr_ready): a combiner gathers the pixels of one DATA_W word (PPB = DATA_W / 32 slots, byte strobes per slot). A write to another word pushes the gathered word into the write queue (fallthrough_fifo, WQ_DEPTH words) and starts the next; a word with every slot written is pushed at once; a partial word is pushed after FLUSH_IDLE clocks without a write (with room in the queue). wr_ready = the queue is not full. Each queued word is one single-beat AXI write (AWLEN 0, full size, INCR, AWID WR_ID, WLAST 1): AW and W presented together, each dropped at its handshake; the next word is loaded once both have gone, while fewer than OUT_MAX writes wait for B (BREADY 1). wr_idle = nothing gathered, queued, presented or waiting for B. - Reads (rd_en with rd_ready = no read active): the four pixels are looked up one per clock in a direct-mapped cache of CACHE_LINES lines of LINE_PIX pixels (line = slot index >> log2(LINE_PIX), set = line mod CACHE_LINES, tag = line / CACHE_LINES). A hit reads the cache RAM (one DATA_W / 32 x PIX_W word, synchronous) and takes the pixel the next clock; a miss loads the line with one AXI read burst of LINE_PIX / PPB beats (ARID RD_ID, full size, INCR; RREADY 1 while loading), each beat written to the RAM as it arrives, valid after the last; the lookup then repeats. rd_valid pulses with rd_data0..3 the clock after the fourth pixel is taken: 5 clocks from the request with four hits. - rd_flush (taken with rd_ready, before a request in the same clock): every line becomes invalid. The cache does not see writes: pulse rd_flush after a rewritten buffer is complete (wr_idle), before reading it. Every output is a register or a function of registers. Parameters: PIX_W (<= 32), ADDR_W (pixel address bits), DATA_W (AXI data, power of two >= 64), AXI_ADDR_W, ID_W, BASE0 / BASE1, LINE_PIX / CACHE_LINES / WQ_DEPTH (powers of two >= 2; LINE_PIX a multiple of PPB, at most 256 beats and 1024 pixels: a line fill never crosses 4 KB), FLUSH_IDLE / OUT_MAX (1 .. 255), WR_ID / RD_ID. Clock - clk (the controller's). Reset - synchronous active low rst_n (the cache RAM keeps its contents). Clock-domain crossings - none. Resources - the cache RAM CACHE_LINES x LINE_PIX x PIX_W bits, the queue WQ_DEPTH x (AXI_ADDR_W + 9 DATA_W / 8) bits. Errors - none reported.

ddr_frame_store is design-local IP of [`vision_system`](../../README.md).
