# coord_gen

Reusable IP. Per-pixel source-address generator. Fast 23-cycle path for radial/tangential distortion and the affine/scaling hooks; a second "slow path" per-pixel divide FSM (reusing fixed_recip) implements fisheye, panoramic, and perspective correction. All multiplies use the mulq_s IP.

coord_gen is design-local IP of [`vision_system`](../../README.md).
