# mulq

Reusable IP. Timing-friendly signed 32x32 multiply with the Q16.16 shift built in: s = (a*b) >>> 16 as an exact 48-bit signed value, in 2 cycles. The multiply is split into four 16x16 partial products (one DSP48 each, registered in stage 1) that are combined in stage 2, avoiding the wide fabric adder that limits a plain 32x32 multiply to ~11 ns. Apply barrel_pkg::qsat48 to get the saturating qmul() result.

mulq is design-local IP of [`vision_system`](../../README.md).
