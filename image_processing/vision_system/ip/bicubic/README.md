# bicubic

Reusable IP. Separable Catmull-Rom (a=-0.5) bicubic RGB888 interpolator over a 4x4 tap footprint, in an 18-stage pipeline (every multiply built on the mulq_s IP). Higher quality than bilinear but does not sustain 1 pixel/clock (see axis_out_ctrl.sv's gather FSM).

bicubic is design-local IP of [`vision_system`](../../README.md).
