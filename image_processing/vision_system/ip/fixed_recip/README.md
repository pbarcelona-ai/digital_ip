# fixed_recip

Reusable IP. Iterative shift/subtract unsigned Q16.16 reciprocal divider (33 cycles). Used in the config plane (once per register write, not per pixel) and, since this project added fisheye/panoramic/perspective support, instantiated a second time inside coord_gen's per-pixel "slow path".

fixed_recip is design-local IP of [`vision_system`](../../README.md).
